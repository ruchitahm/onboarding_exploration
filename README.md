### Onboarding Application
This is a responsive onboarding application inspired by the Dribbble (https://dribbble.com/shots/15669113-Onboarding-Exploration/) design. It allows users to submit entries through a form and view, edit, or delete their submissions.

### Features
- Multi-step onboarding form
- Form validation
- Dashboard to view submitted entries in table format
- Edit and delete functionality for submitted entries
- Responsive design

## Steps to Run Locally
- Clone the repository:
    Clone the repository to your local machine using the following command:
    ### `git clone https://github.com/ruchitahm/onboarding_exploration.git`

- Install dependencies:
    Navigate to the project directory and install the necessary dependencies for the React app:
    ### `cd onboarding_exploration`
    ### `npm install`

- Start the project:
    To start the React app server, use the following command:
    ### `npm start`
    The app should now be running on http://localhost:3000.
